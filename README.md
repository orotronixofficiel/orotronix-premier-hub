# OROTRONIX Premium Launch

Build a professional e-commerce website for my brand OROTRONIX.

IMPORTANT: This is the initial project foundation. Do not ask me to choose between designs or generate multiple alternatives. Make the implementation directly from these requirements.

BRAND:

Name: OROTRONIX

Business: smartphones, phone accessories, TV accessories, and professional phone repair.

Market: Morocco.

Main language: French.

The website must be fully responsive, with a mobile-first approach.

HOME Create a premium homepage with:

Hero section

Featured products

Product categories

Phone repair service section

Pickup & delivery repair service

Special offers

Clear calls to action

Professional footer

SHOP Create a complete shop structure with:

Product grid

Categories

Product cards

Product detail pages

Add to cart

Main categories:

Smartphones

Phone Accessories

TV Accessories

Offers

PHONE REPAIR Create a dedicated repair-service page.

Repair categories:

Screen Replacement

Battery Replacement

Software Problems

Water Damage

Other

Full name

Phone number

City

Address

Phone model

Problem type

Problem description

Additional notes

Include a prominent Pickup & Delivery Repair service section.

CART & CHECKOUT Create:

Shopping cart

Phone number

Cash on Delivery as the main payment method

Order confirmation page

Do NOT add online card payment at this stage.

BASIC ACCOUNT STRUCTURE Prepare the project architecture so customer accounts can be added later, but do not make authentication the main focus of this first version.

FOOTER Include:

OROTRONIX

Repair service

Contact information

Social media

Website

Location

DESIGN DIRECTION: Use a premium, modern technology aesthetic suitable for OROTRONIX.

Preferred visual identity:

Black as the main background

Gold as the premium accent

Clean white/light text where necessary

Elegant typography

Strong visual hierarchy

Spacious layout

Premium product presentation

Subtle animations only

Avoid generic templates and excessive visual effects

IMPORTANT DEVELOPMENT RULES:

Build a clean and scalable architecture.

Use reusable components.

Keep the code organized and maintainable.

Do not use fake functionality for the main user flows.

Do not create an admin dashboard yet.

Do not add advanced payment systems yet.

Do not add unnecessary features.

Focus on creating a strong, professional foundation that we can expand step by step.

For this first build, prioritize structure, navigation, responsive layout, and the main customer journey.
